# Guía de uso del Panel

El Panel gestiona todos los Proyectos Docker de la VPS: deploys desde GitHub, dominios con SSL,
logs en tiempo real y copias de seguridad. Esta guía tiene dos partes: tareas paso a paso para
empezar a usarlo y una referencia de cada pantalla. También está en PDF.

# Parte I — Tareas paso a paso

## 1. Entrar y orientarse

Login, Dashboard, barra lateral, búsqueda y tema.

## 2. Dar de alta un Cliente y su primer Proyecto

Crear el Cliente y un Proyecto compose desde su repositorio.

## 3. Desplegar y seguir el deploy

Lanzar un deploy, seguir sus fases y cancelarlo si hace falta.

## 4. Activar el auto-deploy con el webhook de GitHub

Desplegar solo al hacer push a la rama del Proyecto.

## 5. Añadir variables de entorno

Editar las variables de un Proyecto e importar un `.env`.

## 6. Ver los logs de un contenedor

Logs en tiempo real con filtros por nivel y por Servicio.

## 7. Hacer rollback

Volver al último commit desplegado correctamente.

## 8. Activar los backups

Destino, kit de recuperación y copia diaria.

## 9. Restaurar una copia

Devolver el Panel al estado de una copia.
