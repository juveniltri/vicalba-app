# 2.4.0 — Backups de Proyectos y «Solo desde Cloudflare» — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cerrar el origen a Cloudflare por ruta y copiar/restaurar desde el Panel las BDs y los datos de cada Proyecto, sobre el motor restic de la fase A.

**Architecture:** La Parte 1 añade un campo a `RutaProyecto` y un middleware `ipAllowList` en la config dinámica. La Parte 2 añade en `src/lib/backups/` una detección pura de elementos a partir de `docker inspect`, constructores puros de comandos, un ciclo que encadena la copia del Panel y la de cada Proyecto bajo el bloqueo existente, una retención por elemento y una restauración por Proyecto; todo en streaming a restic (`--stdin-from-command`, `restic dump | …`), sin escribir copias en el disco de la VPS.

**Tech Stack:** Next.js 16, tRPC, Prisma 7 (PostgreSQL), dockerode + CLI de Docker, restic 0.17+, Traefik v3, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-28-2.4.0-backups-proyectos-cloudflare-design.md` (leerlo entero antes de empezar; este plan no repite sus porqués).

## Review Focus

1. **Proyecto sin contenedores** (nunca desplegado o tras un `down`): «Copia ahora» responde «No hay nada que copiar: el Proyecto no tiene contenedores»; el ciclo diario lo salta sin registrar error ni avisar, y no purga nada suyo. → test en la Tarea 9.
2. **Nombres de base con espacios, comillas o mayúsculas** (`"Mi Base"`, `o'neil`): los scripts `sh -c` los citan bien y el `--stdin-filename` sigue siendo un solo segmento. → test en la Tarea 5.
3. **Destino caído al empezar el ciclo diario:** una sola comprobación; si falla, se registra el error de la copia del Panel, no se intenta ningún Proyecto y se envía un solo aviso. → test en la Tarea 9.
4. **Restaurar un elemento que ya no se monta en el Proyecto** (se quitó del compose): ese elemento se rechaza antes de empezar con «<clave> ya no se monta en el Proyecto», sin tocar nada. → test en la Tarea 11.
5. **Claves con comas, espacios o tildes** (`datos:./data/fotos, 2026`): ida y vuelta clave → `--stdin-filename` → clave, y la etiqueta `e:` es el hash. → test en la Tarea 5.

**Interfaces:**

- Produces:

  - `type Proceso = { comando: string; args: string[]; env?: Record<string, string> }`
  - `encadenar(origen: Proceso, destino: Proceso, opciones: { signal?: AbortSignal }): Promise<string>` — stdout de `origen` → stdin de `destino`; resuelve con el stdout de `destino`; rechaza con `ErrorProceso` si **cualquiera** termina con código ≠ 0 o se aborta.
  - `crearSnapshotStdin(r: Restic, p: { proceso: Proceso; nombre: string; etiquetas: string[] }): Promise<{ snapshotId: string; bytesAnadidos: number }>` → `restic backup --json --quiet --host vicalba-panel --tag <cada una> --stdin-filename <nombre> --stdin-from-command -- <comando> <args…>`.

  - `podar(r: Restic): Promise<void>` → `restic prune`.
  - `volcarSnapshot(r: Restic, snapshotId: string, ruta: string): Proceso` → el `Proceso` de `restic dump <id> <ruta>` (para `encadenar`).
